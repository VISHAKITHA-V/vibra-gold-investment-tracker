# Vibra — Gold Investment Tracker

Vibra is a cross-platform mobile application project built with React Native and Expo. It is designed to help users track gold investments and monitor portfolio performance.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- React Native Paper

## Planned Features

- Gold price tracking
- Gold purchase history
- Gold holdings and portfolio tracking
- Investment profit and loss calculations
- Investment progress dashboard

## Getting Started

### Installation

```bash
npm install
npx expo start
```

Follow the Expo CLI instructions to run the application on a device, emulator, or supported web environment.
